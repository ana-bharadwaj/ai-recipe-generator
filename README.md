# AI Recipe Generator

AI Recipe Generator is a full-stack learning project that explores how generative AI can be integrated into a cloud-based web application. The app allows users to enter a few ingredients and receive a recipe suggestion generated by an AI model.  

This project was built primarily as a hands-on exercise to understand how frontend applications, backend services, authentication, and Amazon Bedrock work together in a real-world workflow.

---

## Overview

The application takes a list of ingredients from the user, sends them through an Amplify-powered backend, and generates a recipe suggestion using an AI model hosted on Amazon Bedrock. The result is then displayed back in the frontend in a simple and interactive format.

Although the app itself is lightweight, the project helped demonstrate the complete flow of building a modern AI-powered application, from UI input to backend processing and secure model invocation.

---

## What I Learned

This project helped me understand the full lifecycle of building a generative AI application in the AWS ecosystem.

Some of the main things I learned include:

- How to connect a React frontend with an Amplify Gen 2 backend
- How to define and use custom queries in Amplify
- How Amazon Bedrock can be integrated into an application workflow
- How authentication and authorization affect access to backend operations
- How IAM permissions and signed AWS requests are used instead of exposing model keys directly
- How model access can vary depending on region, throughput mode, and inference profile support
- How to debug frontend-backend communication issues when responses are empty or misconfigured
- How to identify and fix mismatches between authorization rules and client auth modes

A major takeaway from this project was that building an AI app is not just about calling a model. It also requires understanding access control, deployment flow, service configuration, and error handling.

## How to Use the App

1. Open the application in your browser  
2. Enter a list of ingredients separated by commas  
3. Submit the request  
4. Wait for the AI-generated recipe to appear on the screen  

For best results, enter ingredients clearly in a comma-separated format such as:

`tomato, onion, garlic, pasta`

The generated result may include a recipe name, a short description, ingredients, and step-by-step instructions depending on the response format.
